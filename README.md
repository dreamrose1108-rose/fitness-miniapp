# 卡路喵小程序客户端

使用微信开发者工具导入本目录，入口配置为 project.config.json。

## 训练计划

运动页 → 训练计划：提供全身、上下肢、推拉腿通用模板，按四周阶段调整安排。

训练计划 → 凯圣王 × 谭成义三分化：按作者公开跟练简介收录推、拉、腿共 15 个动作，保留各日原视频链接。尚未核实原视频组数、次数、休息及循环规则，数值由用户填写，属于个人安排。支持本机保存、完成标记及开始新一轮。对应关系不明确的动作不绑定替代演示。

来源及动作清单：miniprogram/data/tan-training.js。

## 验证

运行 `node --test tests/*.test.cjs`。2026-11-20 本机 51 项通过；开发者工具验证了参考页显示、训练日切换、保存及进度恢复。

现有 exercise-media.test.cjs 的资源集成检查依赖本机 fitness-backend 的媒体清单以及 reports/exercise-media/publish 下的资源；这些外部资源不包含在客户端源码提交中。其余测试使用源码及 tests/fixtures。

reports 包含本地调试项目、下载媒体和运行报告，不提交。此仓库记录客户端源码，cloudfunctions 为历史目录，本次未部署云函数。GIF 调试资源也未随本次提交发布。
