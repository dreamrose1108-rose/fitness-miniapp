## 待优化，按优先级排序

1. 我的训练安排保存后又变长。training-page.js 的 saved() 清空 draft；schedule.wxml 的动作列表条件为 !draft 或展开键匹配，因此非预览页会展示全部日期的全部动作。建议普通安排默认摘要，仅今日正在训练的卡片展开；保留逐组记录入口。
2. 日历不能定位选中的训练日。calendar.js 的 schedule() 总是打开无日期参数的日程页；过去日期尤其可能被默认过滤。建议传递选中日期，落地页显示并定位对应训练，历史仅查看。
3. 动作库缩略图失败缺少重试。library.js 的 loadThumbnails() 使用空 catch，列表没有明确的加载失败状态。建议保留文字列表并显示一个可重试提示，避免每张图各弹一次窗。
4. AI 计划预览导航失败无提示。coach.js 的 previewPlan() 没有 navigateTo.fail；应复用弹窗反馈并防止连续点击重复打开。
5. 回归测试需要维护。全量 153 项：131 通过，22 失败。多处 VM 测试未注入 feedback 或 wx，出现 feedback.error is not a function / wx is not defined；另有食物库断言与 5:2 行为不匹配，需结合现有未提交改动逐项核对。不能把这些失败都当成线上故障，也不能宣称全量通过。
